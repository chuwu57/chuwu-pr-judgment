# Framework: PR Output Quality Evaluation

## 用途

用于评估传播方案、危机回应、媒体口径、高管发言、campaign 复盘和 AI 生成 PR 内容的质量。

这个框架解决的问题是：PR 输出不能只看「写得像不像」，而要看是否抓住问题、能否被组织执行、是否能被公众接受、是否积累长期信任。

---

# 评分维度

总分 100 分。

## 1. 问题识别：15 分

判断标准：

- 是否识别了真正问题。
- 是否区分业务问题、传播问题、舆情问题和组织问题。
- 是否避免把所有问题都交给 PR 解决。

低分信号：

- 只复述用户需求。
- 没有判断任务是否成立。
- 直接进入写稿或排渠道。

## 2. 事实和证据：15 分

判断标准：

- 是否区分已确认事实、待确认事实和不可公开事实。
- 是否有证据支撑关键判断。
- 是否避免夸大、伪造或过度承诺。

低分信号：

- 用形容词替代事实。
- 没有说明事实边界。
- 生成组织无法兑现的承诺。

## 3. 公共语境：15 分

判断标准：

- 是否理解公众为什么关心。
- 是否识别情绪、平台格式、身份冲突和道德期待。
- 是否判断表达会被谁误读。

低分信号：

- 只从品牌视角解释。
- 把事实正确等同于公众接受。
- 忽略平台传播机制。

## 4. 品牌和业务匹配：15 分

判断标准：

- 是否符合品牌阶段、行业语境和业务目标。
- 是否解释这次传播对品牌资产的影响。
- 是否避免为短期声量牺牲长期信任。

低分信号：

- 方案漂亮但不服务业务。
- 套用通用模板。
- 不考虑行业底线和品牌历史。

## 5. 策略可执行性：15 分

判断标准：

- 是否明确下一步动作。
- 是否说明谁做、何时做、用什么材料做。
- 是否考虑组织资源、法务限制和时间窗口。

低分信号：

- 只有原则，没有动作。
- 输出无法分派给团队。
- 需要不存在的资源才能执行。

## 6. 表达质量：15 分

判断标准：

- 是否清楚、克制、可信。
- 是否区分内部判断和对外话术。
- 是否有适合媒体、公众、高管、客服等不同对象的表达层级。

低分信号：

- 空泛、宏大、套话多。
- 所有对象使用同一套话术。
- 道歉、解释或反击的姿态不匹配事件。

## 7. 风险控制：10 分

判断标准：

- 是否识别潜在误读。
- 是否说明禁区和不可说内容。
- 是否判断回应、沉默、延迟、转移和补救动作的代价。

低分信号：

- 没有风险提示。
- 把回应当成默认答案。
- 只考虑当下止损，不考虑后续追问。

# 质量等级

## A：85-100 分

可直接进入执行或作为高质量内部讨论稿。

要求：

- 判断清楚。
- 事实边界清楚。
- 动作可执行。
- 表达可信。
- 风险已提示。

## B：70-84 分

可以使用，但需要人工校准。

常见问题：

- 策略方向成立，但细节不足。
- 表达可用，但缺少针对性。
- 风险提示存在，但不够完整。

## C：60-69 分

只能作为素材，不应直接使用。

常见问题：

- 结构完整但判断浅。
- 用模板覆盖真实问题。
- 缺少证据和执行细节。

## D：60 分以下

不合格。

常见问题：

- 没有识别真正问题。
- 输出不可执行。
- 存在事实风险或表达风险。

# 使用方式

## 用于 AI 输出审查

先让 AI 按工作流生成结果，再用本框架评分。

重点检查：

- 是否真的回答了任务。
- 是否暴露事实假设。
- 是否存在不能公开的话术。

## 用于团队复盘

项目结束后按七个维度评分。

重点检查：

- 当初判断错在哪里。
- 哪些内容应进入案例库。
- 哪些经验应升级为 Principle、Framework、Strategy 或 Workflow。

## 用于产品化验收

一个 Workflow 如果连续多次输出低于 B 级，不应沉淀为 Skill。

原因：Skill 会放大稳定能力，也会放大错误判断。

# 产品化评分模式

未来产品中，本框架不只作为内部评估文档，而是支撑三类前台能力。

## 1. 结果页评分

适用：

- 用户明确要求评分、质量比较，或复杂方案需要综合评价时；普通生成与小改稿不默认附评分。

展示方式：

- 总分。
- 质量等级。
- 有依据的主要优点与风险，无固定数量；未发现风险时不凑项。
- 在已核事实与授权范围内的适用状态；分数不等同发布许可。
- 只有哪些真实缺口需要用户或业务责任人决定。

判断规则：

- A级：可作为高质量内部讨论稿或执行稿。
- B级：可用，但需要人工校准。
- C级：只能作为素材。
- D级：不建议使用。

## 2. 质检器评分

适用：

- 用户上传已有新闻稿、声明、社媒文案、采访回答、高管发言或方案。

展示方式：

- 发布建议：通过、修改后可用、风险较高建议重写。
- 问题句定位。
- 外部视角模拟。
- 风险类型。
- 替换建议。

判断规则：

- 高风险文案不能因为语言流畅得到高分。
- 事实不清、责任边界不清、承诺无法兑现时，不能给「通过」。
- 涉及公共事件、食品安全、未成年人、动物安全、监管和法律风险时，提高风险权重。

## 3. Workflow成熟度评分

适用：

- 判断一个 Workflow 能否从 Level 1 升级到 Level 2、Level 3、Level 4 或 Skill 候选。

展示方式：

- 使用次数。
- 平均评分。
- 失败案例数量。
- 人工修改点。
- 用户是否能独立完成。
- 是否已有测试用例。

升级规则：

- Level 1 到 Level 2：至少 3 次真实使用，输出平均达到 B 级。
- Level 2 到 Level 3：有失败案例和常见追问规则。
- Level 3 到 Level 4：非维护者可独立使用，输出稳定。
- Level 4 到 Level 5：可自动化，测试用例足够，失败边界明确。

# 任务类型权重调整

不同任务的评分重点不同。

| 任务类型 | 权重提高 | 原因 |
| --- | --- | --- |
| 危机、舆情、口径审查 | 事实和证据、公共语境、风险控制 | 这些任务的主要风险是说错话或做错动作 |
| 新品传播、品牌定位 | 品牌和业务匹配、事实和证据、表达质量 | 这些任务要建立长期认知和信任 |
| 媒体采访、高管发言 | 表达质量、风险控制、公共语境 | 这些任务容易被引用、截图和断章取义 |
| Campaign复盘 | 问题识别、品牌和业务匹配、策略可执行性 | 复盘的价值在于提炼可迁移判断 |
| PRD式任务拆解 | 问题识别、策略可执行性、验收标准 | 这类任务的关键是把模糊需求定义清楚 |
| AI提示词生成 | 输入输出完整性、判断步骤、质量红线 | 提示词会放大任务设计质量 |

# 质检器硬停止

出现以下情况，即使总分不低，也必须给出「风险较高，建议重写」或「不能直接发布」：

- 事实未经确认，却以确定口吻对外发布。
- 以组织无法兑现的承诺安抚公众。
- 把内部判断直接当对外话术。
- 用法务威胁替代公众解释。
- 把责任推给员工、供应商、平台或用户，但没有证据。
- 传播效果依赖冒犯、擦边、恐惧、群体对立或公共事件借势。
- 可能触发食品安全、健康安全、动物安全、未成年人、监管或法律风险。

# 结果页提示文案

当评分低于 B 级时，结果页必须提示：

```text
这份结果只能作为讨论素材，不建议直接使用。请先补充事实、证据或组织动作，再生成发布版本。
```

当事实不足时，结果页必须提示：

```text
当前判断基于不完整信息，以下内容不得直接对外发布。请先确认事实边界和责任边界。
```
