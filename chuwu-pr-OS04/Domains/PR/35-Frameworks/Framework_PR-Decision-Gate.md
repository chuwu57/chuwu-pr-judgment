# Framework: PR Decision Gate

## 用途

在写方案、改文案和讨论渠道之前，先判断一个传播动作是否值得进入执行。它解决的是「做不做、现在做不做、以什么条件做」，不是给成品打一个好看的平均分。

## 五道门

### 1.Reality Gate：事实门

问：品牌准备放大的事实是否真实、可证明、可兑现？

- 通过：关键事实和承诺有证据，产品与服务能够承接。
- 修改：方向真实，但表达超过证据边界。
- 暂停：关键事实仍未知。
- 停止：传播依赖虚构、误导或无法兑现的承诺。

### 2.Harm Gate：伤害门

问：谁正在或可能受到什么具体影响，动作是否先降低伤害？

- 通过：风险可控，并有保护、补救或申诉机制。
- 修改：识别到影响，但处理路径不清。
- 暂停：影响范围无法判断。
- 停止：为了传播或业务目标主动放大他人伤害。

### 3.Context Gate：语境门

问：品牌在当前公共语境中是什么角色，公众此刻需要什么？

- 通过：品牌有正当角色，表达提供真实公共价值。
- 修改：品牌可以出现，但姿态、时间或渠道不匹配。
- 暂停：事件仍快速变化，语境未稳定。
- 停止：品牌只是借灾难、弱势群体或公共价值获取注意力。

### 4.Organization Gate：组织门

问：内部机制是否支持对外表达？

- 通过：事实源、负责人、客服、法务、业务和后续动作已对齐。
- 修改：表达可行，但权限、流程或一线口径需要补齐。
- 暂停：没有人能确认事实或承担承诺。
- 停止：组织明知问题存在，却要求PR掩盖或转移责任。

### 5.Trust Gate：信任门

问：动作是在降低还是增加长期解释成本？

- 通过：增加可理解性、可信度和关系资产。
- 修改：短期目标成立，但会留下可避免的信用成本。
- 暂停：收益和长期代价无法判断。
- 停止：动作只能靠冒犯、夸大、歧义或操纵获得效果。

## 强制治理动作附加门

当方案包含投诉、举报、要求下架、限流、律师函或诉讼时，五道门之后再检查一次。此类动作会改变争议对象：公众可能从评价原内容，转向评价组织如何使用平台、法律与资源优势。

### 1.保护对象

问：正在保护谁的什么具体利益？受影响者是否表达过伤害，还是组织代替他们定义了伤害？

「消费者、粉丝或员工受到冒犯」可以成为待验证假设，不能只靠声明变成行动正当性。若受保护对象不承认这项伤害，组织容易把他人当成反击的名义资源。

### 2.证据与规则

问：内容构成可证明的造谣、侵权、骚扰、操纵或规则违反，还是批评、讽刺和普通玩梗？

只有组织不舒服，不能自动推出平台治理必要性。事实、规则条款和目标内容必须一一对应。

### 3.比例与精度

问：是否只处理造成具体伤害的内容、账号或行为？有没有更窄、可逆、伤害更小的替代路径？

范围越宽，越容易把旁观者、批评者和恶意参与者合并成同一对立面，也越可能制造新的身份动员。

### 4.程序与解释

问：是否有明确理由、证据入口、申诉路径和纠错机制？组织能否解释为什么采取这一强度，而不只宣布自己有权采取？

程序本身是信任证据。无法说明边界的治理动作，会增加外界对任意使用权力的担忧。

### 5.二次传播

问：投诉、删除或法律动作会不会生成截图、复述、替代梗和「被压制」叙事，使原议题获得新的传播理由？

这不是「删除必然反弹」的定律，而是必须估算的二阶风险。低现实伤害、规则边界模糊且动作范围过宽时，观察、举证、公开澄清或定向沟通通常比全面压制更可控。

## 附加门决策

- 保护对象不清、伤害无证据或只是组织情绪受损：不能借消费者、粉丝或公共利益之名采取强制动作。
- 伤害明确、规则清楚：可以精准处理，同时公开边界、证据与申诉路径。
- 事实仍混乱、动作可能大范围波及：先暂停或缩窄范围，再评估二次传播。
- 反击理由只有在「具体利益→可验证伤害→合比例动作→程序保障→结果复核」连成一条链时，才具备公共正当性。

## 决策规则

五道门不能简单平均：

- 任一「停止」→不执行原方案。
- 任一「暂停」且涉及事实、伤害或组织承诺→先补信息，不发布。
- 全部「通过」→可以执行。
- 只有「修改」→修改后重新过门，不直接带病上线。

## 标准输出

```text
主结论：执行／修改后执行／暂停／停止
最大理由：哪一道门决定了结论
五门状态：Reality、Harm、Context、Organization、Trust
必须补齐：事实、责任、动作或证据
替代路径：若原方案停止，怎样实现原业务目标
升级条件：什么变化会触发重新判断
```

## 价值

这个框架把「公关感觉不对」改造成可解释的组织判断。业务能看见问题究竟来自事实、伤害、语境、组织还是信任，也能知道原目标是否可以通过替代路径继续实现。
