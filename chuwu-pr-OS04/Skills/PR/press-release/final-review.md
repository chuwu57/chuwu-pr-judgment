# 新闻通稿终稿审查

只在`SKILL.md`路由到终稿阶段时读取。先完成事实底线、写作失败条件和当前类型卡失败条件的基础检查；发现问题先改稿，再执行本文件。

## 风险检查

- **传播对象不明**：标题和导语没有体现to C、to B、to G或混合对象的可感知变化。
- **群体对立**：制造消费者、非目标人群、品牌、渠道、平台或行业之间的对立、标签或拉踩。
- **企业逐利感过强**：商业数据压过新闻主线；公益稿的企业成绩压过受益对象、机制和成效。
- **自夸自嗨**：使用「行业首创、领先、率先、标杆」等无第三方证据的自封词。
- **理解门槛**：内部黑话、缩写和专业术语没有翻译成公众语言。
- **政策口径**：政策引述没有逐字核对，或把监管要求包装成企业自发行动。
- **对象价值不足**：to C没有消费者获得感；to B没有合作方或产业价值；to G没有治理、规则或公共价值。
- **高调冒进**：承诺尚未落地的计划，或把阶段目标写成确定结果。

## 等级与输出

- 绿色：无明显问题，不展示。
- 黄色：轻微风险或信息缺口，可通过改写、补口径或补案例解决。
- 红色：重大事实、口径或政策风险，须修正后才能标为可发布终稿；可先交付注明缺口的审阅工作稿和已经完成的修正。结构问题按阅读影响处理，不自动阻断交付。

输出终稿正文，以及仍需用户知道的黄色和红色风险。没有黄色和红色风险时，只写「未发现需提示的黄色或红色风险项」，不展示绿色清单和内部检查过程。
