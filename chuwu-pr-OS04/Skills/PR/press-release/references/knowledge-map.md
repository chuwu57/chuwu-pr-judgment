# press-release 知识调用地图

## 核心调用

- `Domains/PR/30-Principles/Principle_PR-Amplifies-Reality.md`：通稿放大事实，不能替代事实。
- `Domains/PR/30-Principles/Principle_PR-Lowers-Trust-Cost.md`：判断稿件是否降低理解和信任成本。
- `Domains/PR/35-Frameworks/Framework_PR-Decision-Gate.md`：发布方向先过五道门。
- `Domains/PR/35-Frameworks/Framework_PR-Output-Quality-Evaluation.md`：问题识别、事实证据、业务匹配、表达质量和风险控制。
- `Domains/PR/35-Frameworks/Framework_PR-Asset-Four-Part.md`：判断稿件沉淀哪类公关资产。
- `Domains/PR/35-Frameworks/Framework_PR-MKT-Value-Difference.md`：区分PR和MKT价值目标。
- `Domains/PR/35-Frameworks/Framework_PR-Business-Contribution-Metrics.md`：选择可解释的商业贡献指标。
- `Domains/PR/35-Frameworks/Framework_Technology-Communication-Translation.md`：技术产品稿件的三层转译。
- `Domains/PR/45-Workflows/Workflow_New-Product-Communication-Plan.md`：新品传播主线不清时调用。

## 理论校准

- 传播学：新闻生产与分布式把关（外部知识条目：`Domains/PR/15-Theory/Communication/20_Media-and-Platforms/Theory_News-Production-and-Distributed-Gatekeeping`）用于判断新闻价值、信源、编辑例行程序和再把关；框架生产与受众解码（外部知识条目：`Domains/PR/15-Theory/Communication/10_Attention-and-Meaning/Theory_Framing-Production-and-Reception`）用于检查稿件如何组织意义；议程动力（外部知识条目：`Domains/PR/15-Theory/Communication/10_Attention-and-Meaning/Theory_Agenda-Dynamics`）用于区分事实价值与组织希望提高的显著性。
- 心理学：有限注意与工作记忆（外部知识条目：`Domains/PR/15-Theory/Psychology/10-Attention-and-Limited-Capacity/有限注意与工作记忆`）、情境模型与要旨表征（外部知识条目：`Domains/PR/15-Theory/Psychology/20-Comprehension-and-Gist/情境模型与要旨表征`）、说服加工与心理抗拒（外部知识条目：`Domains/PR/15-Theory/Psychology/70-Persuasion-and-Resistance/说服加工与心理抗拒`）用于检查信息是否能被处理、读者会形成何种要旨，以及论据或权威线索何时有效。
- 社会学：权力、场域与正当化（外部知识条目：`Domains/PR/15-Theory/Sociology/20_谁有权定义问题与正当答案`）与制度合法性（外部知识条目：`Domains/PR/15-Theory/Sociology/10_制度合法性如何形成失去与修复`）用于检查所谓「权威」的资格来源，以及稿件是在提供可核验事实还是借机构地位索取认同。
