## 理论校准

理论必须落到可观察的风险条件、行动者和结果变量；不以「认知失调」「风险社会」等标签代替风险证据。

- 传播学：危机责任、信源与修辞竞技场（外部知识条目：`Domains/PR/15-Theory/Communication/40_Crisis-and-Risk/Theory_Crisis-Responsibility-Sources-and-Rhetorical-Arenas`）判断责任归因和多声部竞争；风险放大与信息寻求（外部知识条目：`Domains/PR/15-Theory/Communication/40_Crisis-and-Risk/Theory_Risk-Amplification-and-Information-Seeking`）判断信息空缺与社会放大；组织—公众关系与对话（外部知识条目：`Domains/PR/15-Theory/Communication/30_Publics-and-Relationships/Theory_Organization-Public-Relationships-and-Dialogue`）判断既有关系和参与质量。
- 心理学：责任归因与责难形成（外部知识条目：`Domains/PR/15-Theory/Psychology/30-Attribution-and-Blame/责任归因与责难形成`）、信任、可信度与修复（外部知识条目：`Domains/PR/15-Theory/Psychology/40-Trust-and-Repair/信任可信度与修复`）、情绪评价与行动倾向（外部知识条目：`Domains/PR/15-Theory/Psychology/50-Emotion-and-Appraisal/情绪评价与行动倾向`）、个体风险与集体行动（外部知识条目：`Domains/PR/15-Theory/Psychology/90-Intention-and-Action/个体风险与集体行动`）分别校准责难、依赖、情绪和行为升级条件。
- 社会学：制度合法性（外部知识条目：`Domains/PR/15-Theory/Sociology/10_制度合法性如何形成失去与修复`）、一线裁量、情绪劳动与算法控制（外部知识条目：`Domains/PR/15-Theory/Sociology/50_制度如何在一线被重新实现`）、风险、专业知识与制度信任（外部知识条目：`Domains/PR/15-Theory/Sociology/60_不确定性中公众为何接受或拒绝依赖`）、公共问题与集体行动（外部知识条目：`Domains/PR/15-Theory/Sociology/80_个案如何成为公共问题和集体行动`）用于检查行动是否站得住、一线如何变形、公众依赖条件及动员路径。
