# 产品上新 / 升级舆情预案

适用：产品上新、升级、换配方。重点在上线前核对产品事实与宣传主张，区分交付问题、表达超过证据和资料缺口，再确定需要调整的动作。

## 适用分叉
- **全新品类 / 新品**：按现有材料和决策需要选择模块，重点考虑第3、4步（品类卖点认知、竞品测绘）。
- **改款 / 升级 / 换配方**：可略过卖点建模，重在第 5、6 步（历史回查、新旧切换）。

## 分步结构

### 1. 产品事实档案
先把产品真相钉死，这是地基。核心卖点、定位、规格与价格、关键成分 / 材料 / 配置、生产或供应方、各类背书（第三方检测、资质、专利、实验数据，及能否在上线前到位）、视觉物料（升级一定做 before/after 对比）、上新节奏与货盘。写法：客观、可核验，每个数字能落回某份凭证。缺少凭证时先标为证据不足；若主张超过产品实际能力，收窄或撤回主张；若已确认交付本身存在缺陷，再评估产品修正。只有会影响关键承诺或上线判断的缺口才设为前置条件。

### 2. 宣传 claim 合规审查
把品牌想喊的每句卖点过一遍，挑出高危的。四类最该警惕：
- 绝对化或量化主张（如「最」「第一」「0」）：核对对象、条件、检测范围及适用规则，不能只凭单个字判断成立与否；
- 效果与期限承诺（如「X天见效」）：核对适用人群、观察条件和证据是否支持承诺；
- 口径直接挂功效 / 结果 / 健康（最招质疑和监管投诉）；
- 无实证的对比（「碾压某爆款」必须有可公示依据）。

逐条将宣传主张对照凭证，给出保留、限定条件、收窄、撤回或补证建议，说明判断依据。改写也必须得到事实支持：「无明显」同样需要定义观察或检测标准，不能把「0」机械替换为模糊说法。缺少适用规则或专业审核时，明确该项尚未完成核验，不下合规结论。

### 3. 品类与卖点认知建模（上新重，升级可略）
碰到全新品类 / 新材料 / 新技术，建一份底：原理上为什么好、相对旧方案强在哪、稀缺或壁垒在哪、市面还有谁在做。写法：当内部说明书写，每段落点是「所以差异化 / 风险在哪」。这份底子决定被追问「真有用吗」「凭什么比别人好」时有没有据可依。

### 4. 竞品同品类测绘
选同品类、同价格带、同卖点逻辑的对标，扒五样：声量与负面数据（总量、负面量、负面率、起量节点对应它哪次动作）、卖点与宣传口号、对外页面怎么写、客服怎么答、用户主要骂什么。写法：数据先行，取数逻辑写明（机器判定的负面率标注仅供参考）。同类问题用于提示待检查的失败路径；先比较产品、用户和渠道条件，不能把竞品风险直接归为本次已发现风险。

### 5. 历史自身回查（升级重，上新可略）
品牌过往几次改款 / 升级 / 换供应方各自引发了哪类舆情，每次落一句「踩在哪个口上」（品牌、配置、价格、渠道、版本不一致）。写法：归类，不堆案例。目的是识别哪些复发条件在本次仍然存在；历史问题已修复或本次条件不同，应降低相关风险判断。

### 6. 风险分维度审查
用固定维度扫这次产品：价格、成分 / 材料 / 配置、品类与品质稳定性、购买体验、使用中的负面反馈、宣传口径、原创 / 抄袭质疑。升级额外挂一组「新旧切换」专项：新旧混发、换货诉求、版本差异、旧款去哪买（评论区最容易被关联旧负面、被顺手推竞品）。内部按主Skill四态记录：已发现风险、已检查未发现、证据不足、不适用。说明检查依据和范围，缺资料不能写成无风险；正文集中呈现重点风险与影响上线的证据缺口。每项重点风险连接触发、依据、可能后果、动作与责任缺口。

### 7. 异议应答口径准备
把第 6 步每个预判到的质疑，配一条官方站得住的应答口径。是「口径」——客服、官号、详情页三处共用的统一说法，客观、可核验、对得上第 1 步的事实。写法：一问一口径。口径必须能被凭证兜住；缺证时标注待核验，主张超过证据时收窄或撤回，已确认交付缺陷时再评估改产品。预判质疑标为情景假设，不写成已有投诉。

### 8. 落地审核清单
客服话术、产品详情页、上线值班。写法：上线前在三个对外出口（客服界面、详情页、官号）各核一遍——说法是否和事实、和口径一致。

## 重心提醒
宣传审查要与产品事实相连。补证、改宣传和改产品解决不同问题，建议需说明依据及对上线的影响；完成文字改写不能证明产品事实或合规审核已经成立。
