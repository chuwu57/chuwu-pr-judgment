# 宠物食品文案运行门禁

用于猫粮、狗粮、零食、营养补充剂、鲜食、处方粮和宠物品牌传播的日常快速审查。需要核对具体法规、标签声称、品类或渠道边界时，再读取`pet-food-risk-context.md`。

## 总原则

`广告声称≤标签可声称≤证明材料`。无法回落到标签、检测、试验、公开资料或可核验事实的承诺，标记为证据缺口；不得替品牌补造依据。

## 直接停止或暂停

- 明示或暗示预防、治疗动物疾病，替代兽医、药物或处方粮；承诺有效率、治愈率、固定见效时间或绝对安全／健康。
- 使用科研机构、专家、兽医或用户证言作不合规功效证明，或使用不可核验的「临床级、医用级、人食级、婴儿级」。
- 配方、成分、功效、产地、肉源、检测、销量或比较声称超出标签与证据。
- 用「毒粮」、死亡恐吓、羞耻、内疚、消费能力、品种或喂养方式制造对立和购买压力。
- 普通食品包装成处方效果，或弱化「请在执业兽医指导下使用」。

暂停并核对标签／证据的高风险声称：`鲜肉`、`第一肉源`、`含肉量`、`0添加`、`0防腐`、`纯天然`、`进口原料`、`可溯源`、`低脂`、`低能量`、`改善肠道`、`增强免疫`、`美毛`、`去泪痕`、`处方`、`临床验证`及任何绝对化排名。

涉及具体比例时核对规则：`××配方`、`含××配方`、`含××`分别存在26%、14%、4%等定量门槛；比较性高／低／增／降声称需要合法参照和足够变化幅度。不要凭本摘要直接作法律结论，需精确判断时回读详细参考和当前有效规定。

## 六项核对

1.**品类与对象**：区分全价粮、零食、补充剂、鲜食和处方粮；核对猫／狗、生命阶段、体型、生理状态和喂食边界。
2.**功效与成分**：核对疾病暗示、功能声称、配料表、肉源、添加剂、分析保证值、检测和试验。
3.**产地与责任主体**：品牌、生产企业、代工、进口和原料产地表述一致，能够追责。
4.**比较与情绪**：不贬低竞品，不制造国产／进口、干粮／鲜食、品种、消费能力和养宠方式对立。
5.**动物福利与公益**：不使用虐宠、惊吓、过度肥胖、品种歧视、摆拍救助或不可核验捐赠承诺。
6.**渠道**：直播口播、短视频、UGC、小红书种草、KOL和兽医合作的表达不能突破商品标签与证据；个人体验不能变相承担疗效证明。

## 外部视角

按声称与受众选择相关视角：普通养宠人、成分关注者、兽医／临床、动物福利或测评账号等；不要求全部出现。重点模拟「最夸张的一句＋配料表／病宠画面」被截图后的独立叙事。

## 结论边界

- 疾病预防／治疗、虚假功效或虚假成分：标记`原方向停止`，给有证据的替代表达。
- 声称证据暂缺：标记`待补证`，暂停依赖该证据的公开主张，继续审查其余内容，不替品牌判断为合法。
- 恐吓、羞耻或「毒粮」攻击：不得通过。
- 方向成立但存在可修声称、对象或渠道问题：标记`需修改`，修改后重新审查。评分仅在用户要求时使用risk-model.md，不替代这些状态。
