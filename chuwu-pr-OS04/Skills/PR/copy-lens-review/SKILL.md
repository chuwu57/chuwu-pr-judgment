# 文案公共语境审查

> 分享版说明：先读[依赖与使用范围](../../../docs/DEPENDENCIES.md)。本包保留方法与工具，未包含个人知识库、历史案例及运行状态；未附带的知识路径不代表已读取的证据。


> 归属说明：本Skill由初五维护，属于初五的个人Skill体系。分享或再分发时请保留本归属说明及已有来源、作者和许可声明。

判断文案进入评论区、截图、媒体标题和对手视角后是否仍然成立。公共风险取决于语义歧义、群体敏感度、场景严肃度、截图传播性和解释成本；创意流畅不能抵消方向错误。

## 读取路由

- 默认用本文件完成审查，不预读完整知识地图、决策框架和视角库。
- 涉及猫狗食品、零食、营养补充剂、鲜食、配方或功效时读取`references/pet-food-runtime.md`；只有需要核对具体声称、品类、渠道、法规或边缘案例时再读取`references/pet-food-risk-context.md`。
- 只有价值观、身份群体、公共事件或战略取舍存在真实歧义时读取`references/knowledge-map.md`；需要更细群体视角时读取`references/perspective-library.md`。
- 用户明确要求打分时读取`references/risk-model.md`；需要示例时读取`references/example-oppo-mothers-day.md`。

## 审查流程

### 1.先过五道门

内部判断Reality、Harm、Context、Organization、Trust：

- **Reality**：事实、承诺和功效是否真实、可证明、可兑现。
- **Harm**：是否识别并降低对具体群体的伤害。
- **Context**：品牌此刻是否有正当角色，表达是否提供真实价值。
- **Organization**：事实源、责任人、客服、法务、业务和后续动作能否承接。
- **Trust**：动作是在降低还是增加长期解释成本。

任一门「停止」只停止原业务方向；证据不足时暂停依赖它的主张，继续可完成的审查与有依据的改写；可修问题修正后重新判断。复杂或高风险取舍再读取完整`Framework_PR-Decision-Gate.md`，不要在普通任务中重复加载。

### 2.确认上下文与意图

从已有材料核对品牌、行业、渠道、场景、受众和传播目标；只有缺口会改变结论时才向用户提问。用一句话写清创意意图，再分开四层：创作者想表达什么、普通用户会理解什么、敏感或非目标群体会反感什么、截图和媒体标题会放大什么。

### 3.查高风险信号

检查性别、家庭、婚恋、生育、未成年人、老人、弱势群体、地域、职业、阶层、身体／疾病、饭圈黑话、暧昧梗、节日、灾害、公共事件、社会价值借用，以及任何必须解释才能不冒犯的表达。

按本案相关性选择普通用户、非目标用户、受影响群体、媒体或竞品等视角。只保留有具体文本依据且会改变判断的误读，不要求固定群体数量，不虚构已发生的攻击或公众反应。

### 4.判断问题层级

- **措辞问题**：局部词句会误读，修改后可用。
- **框架问题**：站位、对象关系或价值表达不稳，需要重写结构。
- **战略意图问题**：依赖冒犯、优越感、恐惧、擦边或公共价值借用获得传播，停止原方向。

## 硬停止

出现以下情况不能判为「通过」：

- 明确群体对立、冒犯、污名或弱势群体工具化。
- 传播效果依赖歧义、家庭／性别张力、疾病、阶层、地域、未成年人或灾难语境。
- 只有品牌成绩和短期销售／互动，没有用户价值，且会增加解释成本或损耗信任。
- 核心问题无法靠局部改词解决，或组织无法承接对外承诺。

## 结论与输出

内部状态统一为`通过`／`需修改`／`待补证`／`原方向停止`，缺证不等于方向错误，分数不能覆盖事实与伤害门禁。先给判断和主要理由，再按用户任务选择必要内容：

1.创意意图。
2.实际存在的核心风险及机制，可为0项，不凑数。
3.与本案有关的外部视角。
4.确有截断风险时指出具体原句及误读方式；只有用户要求红队推演时才给明确标为假设的标题。
5.对信任、解释成本和品牌资产的影响。
6.可修时给具体改法；方向错误时给保留商业目标的替代方向。

改写时保留合理策略意图，把冲突从敏感身份、家庭伦理、疾病、阶层、地域、未成年人和灾难上移开，落到真实用户价值与可证明事实。

快速初筛可以运行：

```bash
python scripts/copy_lens_review.py input.json --format markdown
```

脚本只返回原文命中信号、规则入口和未覆盖维度，不评分、不判断事实、不生成发布许可、媒体标题或改写。未命中不代表安全；由模型结合证据完成最终审查。若最后需要在传播效果和长期风险之间拍板，把事实、风险、替代方向和不确定性作为最小交接包交给`judgment-hub`。
