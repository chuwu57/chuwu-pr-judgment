# judgment-hub 知识调用地图

## 第一优先级：专项 Skill 与实战判断

- `Skills/PR/hot-public-opinion-analysis`：外部事件是否成势、实质、走势和业务启示。
- `Skills/PR/media-narrative-analysis`：稿件或竞对传播在建立什么认知。
- `Skills/PR/pr-contingency-plan`：上线前风险地图、口径和动作清单。
- `Skills/PR/copy-lens-review`：文案公共语境风险。
- `Skills/PR/press-release`：新闻稿价值、事实边界和发布风险。

## 第二优先级：框架、策略和 Workflow

- `Domains/PR/30-Principles/Principle_PR-Is-Business-Judgment.md`：PR 是经营判断，不是单纯传播执行。
- `Domains/PR/30-Principles/Principle_Crisis-Action-Before-Narrative.md`：危机先降低真实伤害，再争取解释。
- `Domains/PR/30-Principles/Principle_Public-Context-Overrides-Brand-Intent.md`：公共语境高于品牌主观意图。
- `Domains/PR/35-Frameworks/Framework_PR-Decision-Gate.md`：事实、伤害、语境、组织和信任五道门；先判断做不做。
- `Domains/PR/35-Frameworks/Framework_PR-Asset-Four-Part.md`：判断动作影响哪类公关资产。
- `Domains/PR/35-Frameworks/Framework_Public-Opinion-Level-Three-Dimensions.md`：判断舆情量级。
- `Domains/PR/35-Frameworks/Framework_Crisis-Emotion-High-Voltage.md`：识别情绪高压线。
- `Domains/PR/35-Frameworks/Framework_CRI-5R-Crisis-Judgment.md`：区分事件烈度与处置质量。
- `Domains/PR/35-Frameworks/Framework_Media-Value-Exchange.md`：判断媒介资源交换边界。
- `Domains/PR/35-Frameworks/Framework_Single-Source-Layered-Voice.md`：统一事实并按渠道适配语态。
- `Domains/PR/35-Frameworks/Framework_PR-Output-Quality-Evaluation.md`：问题识别、事实证据、公共语境、业务匹配、可执行性、表达质量和风险控制。
- `Domains/PR/35-Frameworks/Framework_Public-Opinion-Format-Response.md`：事实层、格式层、平台层、身份层和道德层。
- `Domains/PR/35-Frameworks/Framework_SCCT-Response-Matching.md`：责任归因、公众情绪和回应强度匹配。
- `Domains/PR/45-Workflows/Workflow_Public-Opinion-Response-Decision.md`：从专项Skill交接时只承接Step4—8的回应取舍、姿态、格式、口径边界与复盘，不返回Step1—3重做舆情判断；直接模式不进入本Skill。
- `Domains/PR/45-Workflows/Workflow_Crisis-Contingency-Plan.md`：风险、触发条件、处置动作和口径。

## 第三优先级：理论校准

理论只用于校准判断，不直接写成答案主轴。

- 先从跨学科问题链（外部知识条目：`Domains/PR/15-Theory/00_Problem-Chains/README`）按真实问题进入，再回到相应理论专论核验机制和边界。
- 传播学总入口：传播理论到PR判断（外部知识条目：`Domains/PR/15-Theory/Communication/00_MOC/传播理论到PR判断`），用于区分注意、意义、媒体／平台、公众关系、危机风险与扩散机制。
- 心理学按机制进入：注意（外部知识条目：`Domains/PR/15-Theory/Psychology/10-Attention-and-Limited-Capacity/有限注意与工作记忆`）、理解（外部知识条目：`Domains/PR/15-Theory/Psychology/20-Comprehension-and-Gist/情境模型与要旨表征`）、责难（外部知识条目：`Domains/PR/15-Theory/Psychology/30-Attribution-and-Blame/责任归因与责难形成`）、信任（外部知识条目：`Domains/PR/15-Theory/Psychology/40-Trust-and-Repair/信任可信度与修复`）、情绪（外部知识条目：`Domains/PR/15-Theory/Psychology/50-Emotion-and-Appraisal/情绪评价与行动倾向`）、身份（外部知识条目：`Domains/PR/15-Theory/Psychology/60-Identity-and-Motivated-Cognition/社会认同与动机性认知`）、说服（外部知识条目：`Domains/PR/15-Theory/Psychology/70-Persuasion-and-Resistance/说服加工与心理抗拒`）、纠错（外部知识条目：`Domains/PR/15-Theory/Psychology/80-Misinformation-and-Correction/错误信息记忆纠错与预防`）与行动（外部知识条目：`Domains/PR/15-Theory/Psychology/90-Intention-and-Action/个体风险与集体行动`）。
- 社会学总入口：社会理论到PR判断（外部知识条目：`Domains/PR/15-Theory/Sociology/00_MOC/社会理论到PR判断`），用于区分制度合法性、定义权、边界与污名、一线实践、风险依赖、网络扩散及公共行动。

## 使用边界

- 不因理论成立就直接建议动作，必须回到事实、业务目标和组织承受能力。
- 不因案例相似就机械套用，必须判断行业、品牌阶段、平台和公众情绪是否相同。
- 不把所有分歧升级成危机；只有影响资产、业务或组织信任时才升级。
