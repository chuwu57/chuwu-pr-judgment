## 理论校准

只调用完整理论链，不用「框架效应」「锚定效应」「确认偏误」替代文本与制度证据。

- 传播学：新闻生产与分布式把关（外部知识条目：`Domains/PR/15-Theory/Communication/20_Media-and-Platforms/Theory_News-Production-and-Distributed-Gatekeeping`）解释新闻价值、信源、编辑例行程序和平台再把关；框架生产与受众解码（外部知识条目：`Domains/PR/15-Theory/Communication/10_Attention-and-Meaning/Theory_Framing-Production-and-Reception`）解释问题定义、因果、评价与方案；议程动力（外部知识条目：`Domains/PR/15-Theory/Communication/10_Attention-and-Meaning/Theory_Agenda-Dynamics`）解释议题与属性显著性如何形成。
- 社会学：权力、场域与正当化（外部知识条目：`Domains/PR/15-Theory/Sociology/20_谁有权定义问题与正当答案`）解释谁有定义权；制度合法性（外部知识条目：`Domains/PR/15-Theory/Sociology/10_制度合法性如何形成失去与修复`）解释稿件在确认或挑战何种制度秩序；品味、边界与评价（外部知识条目：`Domains/PR/15-Theory/Sociology/30_品味边界分类如何制造尊严与不平等`）解释分类标准如何制造地位差异。
- 心理学：情境模型与要旨表征（外部知识条目：`Domains/PR/15-Theory/Psychology/20-Comprehension-and-Gist/情境模型与要旨表征`）解释读者如何从文本形成因果故事；社会认同与动机性认知（外部知识条目：`Domains/PR/15-Theory/Psychology/60-Identity-and-Motivated-Cognition/社会认同与动机性认知`）解释何时出现身份相关的选择性加工；信任、可信度与修复（外部知识条目：`Domains/PR/15-Theory/Psychology/40-Trust-and-Repair/信任可信度与修复`）区分信源可信度、组织声誉与依赖意愿。
