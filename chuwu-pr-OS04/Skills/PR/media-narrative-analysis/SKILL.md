# 稿件分析

> 分享版说明：先读[依赖与使用范围](../../../docs/DEPENDENCIES.md)。本包保留方法与工具，未包含个人知识库、历史案例及运行状态；未附带的知识路径不代表已读取的证据。


> 归属说明：本Skill由初五维护，属于初五的个人Skill体系。分享或再分发时请保留本归属说明及已有来源、作者和许可声明。

## 定位

从原文的选材、措辞、结构和信源判断它可能建立什么认知，再评估对我们的影响。文本可以支持叙事判断，但通常不足以确认作者或机构的真实动机。

本 Skill 处理三类问题：

- 这篇稿有哪些可观察的叙事选择，可能产生什么认知效果；传播意图有多少证据支持。
- 它对我们有没有影响，影响哪类公关资产。
- 我们需要不应对、观察，还是进入判断中枢拍板。

不要把它做成「软文识别器」。软文只是其中一种可能，真正要判断的是：这篇稿是否改变了行业认知、竞品位置、媒体关系、话语体系或我们的解释成本。

## 知识调用

默认按本文件完成稿件分析。遇到竞品叙事、行业标准争夺、政策协作稿、媒体关系、新闻价值或是否投入资源的问题时，读取 `references/knowledge-map.md`。涉及媒体动机、机构号、商业信号、新闻稿依赖、企业信源主导或同一事件多个媒体版本时，同时读取`Domains/PR/35-Frameworks/Framework_Media-Signal-Calibration.md`。

知识只用于校准来源、发布时间、表达选择和业务影响。不要把传播学概念替代具体原文依据，也不要用理论或历史印象补出未证实的幕后推动者。

## 先做事实核验

先区分任务模式：

- 用户已提供全文并要求评价时，默认基于原文完成叙事判断；把关键外部主张标记为待核验，不自动扩大为网页调查。
- 用户明确要求事实核验、最新情况、传播矩阵判断，或关键事实真假会改变行动建议时，只检索会改变结论的部分。
- 需要检索时，先形成基于原文的初步判断，再补最小必要核验，不能让检索替代文章分析。

分析前先确认：

- 标题、作者、平台、发布时间、原始链接。
- 区分原创、转载等来源关系，以及通稿、访谈、评论、研究文章、政策通报等体裁。商业合作或投放另看明确标识和公开证据，不能从体裁直接认定。
- 是否有同题材稿件同步出现。必要时搜索标题关键词、核心事件和关键句，判断它是不是矩阵传播的一部分。
- 关键事实是否来自单一信源，信源能证明什么、哪些主张缺少独立核验。内部数据或独家场景可能来自采访准入、材料可得性或报道范围，单方受益不能单独证明策划或付费关系。

不能确认的内容要写清楚「未确认」，不要把猜测当结论。

## 校准来源与编辑加工

把媒体身份当作研究先验，不当作文章真假或立场的最终判断。只要任务涉及「媒体为什么这样写」「是不是软文」或传播矩阵，必须补做四项校准：

1. 判断来源角色及其接近事实的路径；
2. 标出核心事实来自企业、监管、客户、员工、专家、媒体现场、独立测试还是作者体验；
3. 判断编辑加工层级：L1承载／转载、L2技术注释、L3编辑采访、L4多方调查；
4. 分开写商业结构、企业影响和付费证据。没有明确公开证据时，不判断具体文章属于付费合作。

加工层级不是可信度总分。L4仍受样本和匿名信源限制；L1可以准确承载一手声明，但只能证明声明本身。

## 判断顺序

### 1. 先给结论

第一段直接回答：

- 原文最明显的叙事选择及其可能建立的认知；证据不足时保留意图未知。
- 对我们是无关、观察，还是需要动作。
- 影响的是短期声量，还是长期信任、话语体系、媒体关系、业务解释成本。

### 2. 分开观察、效果与意图

分析时保留三层，不要求正文逐条填写固定表格：

- **原文可观察选择**：写了哪些事实、引用谁、如何排序和对比、明确省略了哪些与结论有关的条件。每项判断连接原文片段或可定位的表现；不能把自己未见到的信息一律认定为作者刻意回避。
- **可能认知效果**：这些选择可能让哪类读者形成什么理解，说明从文本到理解的路径。未取得受众反馈时，只能判断潜在效果，不能把预期效果写成已经发生的舆论变化。
- **传播意图假设**：只有意图判断会改变分析或建议时才展开，说明支持线索、合理替代解释和会削弱判断的证据。单方受益、语气正面、同日发稿或企业信源占比高，都不足以独立证明协调传播、作者动机或付费合作。

按原文相关性考察以下问题：

**谁获得叙事优势**

看谁被突出、谁受到批评、采用了谁的评价标准。区分「某方受益」与「某方推动发布」；后者需要发布安排、公开合作说明等额外证据。没有证据时不补出幕后推动者。

**发布时间有什么解释**

如有可靠时间信息，可对照财报、政策、行业事件或产品节点。也应考虑常规排期、新闻时效、转载延迟和偶合。只知道发布时间时，不硬写时机意图；不同发布时间或独立采编记录可能削弱协调传播假设。

**表达选择有什么作用**

分析标题、体裁、数据和信源如何支撑论点。普通编辑取舍、篇幅限制、专业分工、可取得的材料以及真实新闻价值，都可能解释单一角度或正面语气。专访、评论、研究稿等体裁提示信息获取与表达方式，不能直接推定控制度。若原文保留反例、不利事实或独立核验，应相应降低单方操控的判断强度。

### 3. 提炼核心断言

提炼支撑全文的核心断言，避免逐段摘要。先写文本明确主张什么，再解释可能引向的理解，不替作者补写未表达的意图。

区分三层：

- 事实陈述：它明说了什么。
- 价值判断：它暗示谁更好、更先进、更负责任。
- 隐含预设：它默认什么标准是对的。

### 4. 看叙事动作

只写这篇稿有原文依据的表达选择，不堆术语。下面是待检查的可能机制；「包装」「回避」等带意图色彩的判断需要额外依据，否则描述其可观察表现。

常见动作包括：

- 用词重新定义行业标准。
- 只放大有利数据，淡化不利条件。
- 用第三方、专家、研究员、用户故事降低防御。
- 用政策、技术、公益、AI、社会责任包装商业动作。
- 通过对比结构制造优劣感。
- 点名一方短板，同时回避另一方问题。
- 把企业动作嵌入更大的社会议题，借公共价值获得合法性。

### 5. 判断内容性质与证据边界

结合信息增量、信源独立性、编辑核验和立场倾向给出判断，不强制归入互斥标签。例如：

- 多方核验型报道：多方信源、事实增量明确，关键主张经过交叉检查。
- 单方材料主导的介绍或解读：可以包含真实信息，但独立核验有限；说明具体依赖哪些材料。
- 观点或倡议内容：评价标准与立场鲜明，分别检验论据和推论，不把立场本身当作操纵证据。
- 批评性报道：检查问题证据、采访范围、被批评方回应和反例，不能从批评方向猜测推手。
- 政策相关内容：区分政策原文、企业案例与作者评价，检查争议条件是否得到处理，不凭正面关联认定合作。

用户问「是不是软文」时，直接回答可确认的宣传倾向、信息价值与核验程度。付费状态只有明确公开证据才下结论；证据不足就写无法确认，不能用「疑似付费」绕过证据要求。

### 6. 判断对我们的影响

不要把所有竞对稿都写成威胁。只看它是否改变我们的工作条件。

重点判断：

- 是否直接点到我们。
- 是否创造了对我们不利的行业标准。
- 是否让竞对获得新叙事位置。
- 是否提高我们后续解释成本。
- 是否影响舆论资产、媒体关系资产、话语体系资产、内部判断资产。
- 是否和生意相关：用户心智、渠道承接、政策语境、资本市场、品类教育、风险治理。

结论分三档：

- **无需处理**：与我们关系弱，回应反而放大。
- **持续观察**：叙事有影响，但还没形成可行动威胁。
- **需要动作**：已影响资产或业务判断，需要回应、预案、发稿或判断中枢拍板。

## 输出组织

先回答文章可能建立什么认知、对我们是否需要动作，再用最关键的原文依据支撑。按材料密度组织连贯正文；简单文章可用几个段落，复杂文章再分来源与证据、叙事选择、业务影响、建议动作。不强制逐项展示内部分析流程，也不为填满栏目推测发布时间或动机。

正文应让读者辨认哪些是原文观察、哪些是潜在效果、哪些是意图假设。只有会改变判断的意图假设才展开替代解释和反证边界；无证据的意图可以留空。建议动作落到不处理、观察触发点或已有依据的专项行动；没有未决取舍时不强制进入判断中枢。

## 质量红线

- 不复述原文。
- 不把「可能」堆满全文。证据不足就写证据不足；能判断就给判断。
- 不用「框架设置」「议程设置」这类词当段落标题。
- 不把普通稿子抬成重大威胁。
- 不为了显得全面列无关部门。
- 不编造投放关系、媒体立场、作者动机，不从有利效果倒推动机。
- 不把可能认知效果写成真实受众反馈，不把普通编辑选择自动解释为精心操控。
- 不用媒体类型或既有印象代替对本文信源和加工过程的判断。
- 不用「软文」两个字替代完整判断。

只有回应、反制或业务动作仍存在真实取舍时，才转入`judgment-hub`收口。用户已明确请求稿件或预案且方向已成立时，继续完成相应专项产物，不重复拍板。
