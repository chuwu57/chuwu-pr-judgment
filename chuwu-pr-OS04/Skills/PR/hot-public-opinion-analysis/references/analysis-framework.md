# 舆情分析补充框架

运行状态、决策主体、时间锚点和交接边界统一采用SKILL.md；本文件仅补充分析维度，不创建第二套分档或强制子Agent流程。

## 证据与传播分开

对每条关键事实核对原始来源、时间、对象、可核验范围及利益关系。官方声明可证明组织作过该声明，不能自动证明所有争议事实；网帖可证明当事人提出了某项说法，是否真实需进一步证据。冲突按具体主张、原始材料和独立验证处理，未解决时并列保留。

传播状态包括已形成、前夜、尚未形成与「传播证据不足，暂不可分档」；没有连续传播证据时，阶段写「暂不可判断」。历史切片不能代表当前。低热度或传播未知不妨碍处理已知伤害和业务责任。

## 机制分析

只保留能够解释当前证据的机制：受影响者、利益分配、责任归因、预期落差、公共标签、平台放大与历史语境。不要为凑深度发明群体冲突。主动检查最有力的替代解释和反例；理论仅在增加解释力时使用，不要求数量、反直觉结论或独立子Agent。

## 条件走势与业务影响

把升级、降温或反转写为有证据的条件关系，说明新增证据、传播节点、行动变化或时间窗口。区分事实、假设与未知，不做确定预测。

业务建议指向具体自查、保护、核验或沟通准备。已有授权的本次工作继续完成；组织外部行动与新的授权按实际范围处理。无业务相关性时可以建议观察，不强制建立监测任务。
