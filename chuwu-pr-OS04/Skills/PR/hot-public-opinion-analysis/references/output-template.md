# 可选舆情研判结构

按用户所需深度选用以下内容；一句话或快速判断可以合并段落。使用SKILL.md的状态与证据边界，不要求固定字数、标题、理论或子Agent。

- 判断基准：决策主体、时间锚点、关键证据及缺口。
- 传播状态：已形成／前夜／尚未形成／传播证据不足，暂不可分档；附支持判断的范围。
- 事件实质：已核事实、争议说法、受影响者与解释机制；区分推断。
- 条件走势：有连续证据时给阶段，否则写阶段暂不可判断；说明升级与降温条件。
- 业务意义：相关责任、已知伤害、具体核验或行动建议。热度不足不阻断伤害处置。

无需重复所有字段。事实不足时交付有边界的当前判断和待补事项；用户要求的已授权后续方案继续完成，不停在「欢迎进一步讨论」或交接包。
