- 心理学：有限注意与工作记忆（外部知识条目：`Domains/PR/15-Theory/Psychology/10-Attention-and-Limited-Capacity/有限注意与工作记忆`）、责任归因与责难形成（外部知识条目：`Domains/PR/15-Theory/Psychology/30-Attribution-and-Blame/责任归因与责难形成`）、情绪评价与行动倾向（外部知识条目：`Domains/PR/15-Theory/Psychology/50-Emotion-and-Appraisal/情绪评价与行动倾向`）、社会认同与动机性认知（外部知识条目：`Domains/PR/15-Theory/Psychology/60-Identity-and-Motivated-Cognition/社会认同与动机性认知`）、个体风险与集体行动（外部知识条目：`Domains/PR/15-Theory/Psychology/90-Intention-and-Action/个体风险与集体行动`）。
