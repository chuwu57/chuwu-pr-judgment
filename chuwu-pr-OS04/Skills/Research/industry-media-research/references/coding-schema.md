# 行业媒体研究编码底稿

仅在执行`industry-media-research`时按需读取。本文件提供最低可复核字段、分类方法和输出证据规则。

媒体对象表用于建立观察范围和信息功能地图，不用于评价媒体高低。文章编码用于理解认知如何形成，不产生媒体总分。

## 1.媒体对象表

| 字段 | 说明 |
| --- | --- |
| entity_id | 稳定编号，如`CN-M-01` |
| entity_name | 机构、栏目、Newsletter或创作者名称 |
| entity_level | 机构／子栏目／作者／创作者／社区／研究机构／活动 |
| parent_entity | 所属机构；没有则留空 |
| region_language | 地域与主要语言 |
| primary_role | 综合新闻／财经商业／科技创新／行业垂直／研究政策／创作者／社区平台／行业基础设施 |
| audience_task | 读者来这里获得什么 |
| platform_format | 网站、公众号、Newsletter、播客、视频等 |
| coverage_status | 核心样本／补充样本／边界样本／待确认／不纳入 |
| coverage_reason | 研究相关性、覆盖功能、样本或访问理由；不记录价值高低 |
| sample_count | 已编码原创样本数 |
| access_limit | 付费墙、索引、登录、地区或语言限制 |
| last_checked | 最后检索日期 |

主体类型和媒体功能分开记录。同一机构可以拥有不同子栏目与内容功能；研究机构、活动和公司官方渠道可以是重要信息源，但不要自动当作独立编辑媒体。

## 3.访问与缺席状态

三种状态不能互换：

- **样本中未出现**：在已编码样本里没有出现，可以对当前样本成立。
- **检索未发现**：做过检索但没找到，可能受关键词和索引影响。
- **无法确认**：付费墙、登录、删除、地区限制或语言能力导致不能判断。

## 4.编辑与证据组织方式L1—L4

| 标记 | 判断依据 | 常见证据 |
| --- | --- | --- |
| L1 | 主要承载或轻度改写公开材料 | 新闻稿、公告、公开演讲、演示视频 |
| L2 | 加入背景、解释、有限比较或校验 | 历史资料、术语注释、公开数据横比 |
| L3 | 形成独立采访与编辑组织 | 多位受访者、独立数据、现场或产品验证 |
| L4 | 多方调查与系统核验 | 反方、文件、长期跟踪、现场调查、事实核查 |

标记是文章属性，用于观察一项主张经过了怎样的编辑与证据组织。它不是质量分数，也不代表对应媒体的高低。对媒体做总结时只能写样本分布，如「6篇样本中L1为2篇、L2为3篇、L3为1篇」。

## 5.归纳分类法

### 第一步：开放编码

逐篇写出：它在回答什么问题、服务什么读者任务、用什么结构、主要证据来自谁。

### 第二步：聚合

把机制相近的样本聚到一起，检查共同点是否跨越不同事件。只因标题语气相似不能成为一类。

### 第三步：命名

用「读者任务＋叙事机制」命名，避免空泛的「深度型」「专业型」「故事型」。

### 第四步：反例测试

为每类寻找至少一个边界样本，回答：它为什么属于另一类、是否需要主次类型、原分类是否过宽。

### 第五步：稳定性标记

- 稳定：多个对象、多个事件重复出现。
- 暂定：样本重复但范围较窄。
- 特殊样本：当前只有孤例。

类别数量由样本决定。跨国比较时共享编码字段，不强求共享最终类别。

## 6.写作特征的归因层级

每条特征先标记层级：

- 样本层：这篇文章怎样写。
- 作者层：同一作者在多篇文章中的重复选择。
- 栏目／格式层：特定栏目、Newsletter、播客或视频的固定机制。
- 机构层：跨作者、跨议题仍重复出现的编辑倾向。

快速模式下，机构层写法默认使用「在本次样本中呈现」；没有跨作者样本时不得写成稳定house style。

## 7.关键结论证据格式

建议使用：

> 判断：在本次8篇样本中，该栏目常以人物场景进入技术议题。
>
> 证据：S02、S04、S05、S08；其中3篇由不同作者完成。
>
> 反例：S07直接从融资数字进入。
>
> 边界：只覆盖2026年3—7月的具身智能栏目，不能代表该机构全部科技报道。
>
> 认知贡献：该栏目主要通过人物经验帮助读者进入技术议题，但融资数字入口的反例说明它并未固定采用人物化叙事。
>
> 可选公关启示：若需要向该栏目提供材料，人物素材应同步配套第三方数据和阶段限定。

## 8.集中案例库

媒体地图和结构表只保存压缩判断。具体案例集中放在表格后，每个案例包含：

- 标题、媒体、作者、日期、原始链接。
- 选择原因。
- 一段结构拆解。
- 它支持哪条判断。
- 它不能证明什么。

案例库用于复核与练习，不用案例数量制造研究完整感。
