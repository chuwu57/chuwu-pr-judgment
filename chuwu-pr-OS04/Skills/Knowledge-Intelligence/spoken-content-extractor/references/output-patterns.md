# Output Patterns

Use these patterns only when relevant to the user's requested deliverable.

## Content Extraction Brief

- 基本信息: title, link/file, source type, date, duration, speakers.
- 一句话结论: the most useful single takeaway.
- 核心摘要: concise narrative summary.
- 主题脉络: ordered topic map, with timestamps or source sections.
- 关键观点: bullets grouped by speaker or topic.
- 事实与证据: names, figures, cases, examples, claims that need traceability.
- 可引用表达: label each item as verbatim or paraphrase.
- 待核实点: claims that need confirmation outside the source.

## PR And Media Brief

- 新闻钩子: why this matters now.
- 核心口径: 3-5 defensible messages.
- 可被媒体引用的表达: short and non-exaggerated.
- 敏感点: regulatory, competitor, employee, customer, or market claims.
- 不建议外发的表述: lines that are too absolute, emotional, or unverifiable.
- 追问准备: likely journalist or audience questions with grounded answers.

## Social Repurposing

- Xiaohongshu: concrete scene, human problem, useful takeaway; avoid corporate slogans.
- WeChat article: title options, opening angle, section outline, closing call-to-action.
- Weibo/Threads style short posts: one clear point per post.
- LinkedIn: professional insight, decision framing, business implication.

## Transcript Handling

- If the source is an imperfect transcript, preserve uncertainty with markers such as `[听不清]`, `[疑似]`, or `[待核实]`.
- If speaker names are unknown, use `主持人`, `嘉宾A`, `嘉宾B` consistently.
- If timestamps are unavailable, use section headings instead of fake timestamps.
