# Study Guide Patterns

Use this reference when the user asks to learn from a podcast, make knowledge usable, highlight the transcript, build a study guide, find references, or turn ideas into work/personal-growth frameworks.

## Default Study Guide

```markdown
# 《标题》学习手册

来源：
逐字稿：

## 先给结论

## 你应该重点学什么

### 1. 主题
- 播客观点
- 为什么重要
- 怎么迁移到你的工作/生活
- 自检问题

## 值得高亮的内容

## 一张知识地图

## 复盘问题

## 延伸阅读

## 怎么把它用于你的工作

## 建议的二刷方式
```

## Highlight Rules

- Use timestamped transcript excerpts when available.
- Label paraphrases as paraphrases.
- Keep direct quotes short and only when they are important.
- Prefer "what this helps the user decide/do" over generic summary.
- Surface tensions: where the speaker's claim is useful but not universally true.

## Learning Lens

For each major idea, answer:

- What is the claim?
- What problem does it solve?
- What metric or evidence would test it?
- Where could it fail?
- How can the user apply it this week?

## Reference Reading

When adding references, prefer:

- Classic books or papers for core concepts.
- Official or primary sources for frameworks.
- Recent credible industry analysis only when timeliness matters.
- A short reason for each reference: what it helps the user understand.

Useful recurring concepts:

- Price elasticity of demand
- Consumer surplus
- Brand equity
- Premium pricing and price architecture
- North Star metric
- Marketing ROI and funnel metrics
- Retention, churn, survival analysis
- Customer lifetime value (CLV/LTV)
- Cross-sell and customer journey design
- Information asymmetry and search costs
- AI search, AI agents, and knowledge distribution

## Application Outputs

For business users, include:

- brand diagnosis questions
- metric checklist
- content strategy implications
- customer education opportunities
- risks and assumptions to verify

For personal growth users, translate business concepts:

- price rigidity -> irreplaceable value
- repeat purchase -> people choose to work with you again
- cross-sell -> adjacent capabilities
- CLV -> long-term trust and opportunity value
- information arbitrage risk -> skills likely to be commoditized by AI
