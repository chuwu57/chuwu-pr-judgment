# Follow Loop Case Follow传播方法底图

版本：2026-07-24

用途：每轮发现前，先知道PR知识库已经有哪些可复用判断和方法。新案例先判断完整性与借鉴价值，再判断它是验证、挑战、补充边界、重新组合，还是提出真正的新方法。

这是Case Follow的导航底图，不是新的知识本体。真实定义、证据和边界以所链接的Principle、Framework和Strategy为准。

## 先说清「成立」

一个单案能支持的最强结论是：「这个方法在这些条件下值得借鉴。」它不能单独证明一条普遍规律。

「值得借鉴」同时满足：

1. 真实：关键传播行动确实发生，不只是企业自述或计划。
2. 完整：能还原问题与语境、目标公众、公开行动、认知目标、传播路径、结果证据和方法边界。
3. 相称：方法结论没有超过当前证据。声量只证明被看见，不自动证明被理解、被信任或形成长期效果。
4. 可迁移：能说清可复用的变量和执行条件，不依赖该品牌的体量、符号或偶然流量才成立。
5. 有边界：能说清哪些条件下会失效、反转或不能照搬。
6. 可持续：不依赖虚假、隐瞒、操纵或把代价转嫁给更弱的利益相关方。

只要缺少决定性的结果、履约、独立核验或持续性证据，就保持「待验证」。

> 完整性决定能不能学，证据决定能不能信，迁移性决定值不值得留，新意只决定它有多少增量。

## 当前结构性缺口

1. 危机、证据沟通和技术可信度已经有较完整的原则、框架、策略和多案例支持。
2. 正向的品牌建设、产品参与、社群关系、公益、B2B能力可视化和地域品牌方法，目前多以历史核心模型或单个案例存在，缺少同等完整的多案例验证。
3. 因此，Case Follow不应只找「知识库从没有见过」的动作；它还应主动找到能把这些薄弱方法补完、验实或否证的案例。

## 每轮对照方法

每个候选固定回答：

1. 它在上述哪个方法簇中？如果不在，为什么？
2. 它对已有方法是验证、挑战、补充边界还是重新组合？
3. 方法链条缺哪一环？该缺口会不会改变「值得借鉴」的结论？
4. 它的新意发生在方法、组合、场景、对象、证据还是边界？没有新意时直接写「无新意但验证充分」。
5. 最后才决定它是值得借鉴、待验证、反例或边界，还是信息不足或偏题。
