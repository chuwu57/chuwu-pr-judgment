# Luxury Follow对象演化与信号模型

## 目标

持续判断全球与中国奢侈品行业的需求、品牌、产品、文化、渠道和经营如何演化。研究对象可以是集团、品牌、长期研究者或稳定行业命题；不把时装周热度、单品榜单和社媒声量直接当作品牌吸引力。

## 七层坐标

1.需求结构：地区、客群、价格带、品类和场景怎样变化。
2.产品与价格：产品创新、核心品类、价格提升、价值感和质量反馈是否匹配。
3.品牌吸引力：消费者为什么仍愿意选择、到店、等待和支付溢价。
4.文化创造：创意领导、工艺、历史、艺术与社群如何形成当代意义。
5.渠道与控制：直营、批发、电商、折扣、二手、旅游零售和门店网络怎样调整。
6.客户体验：门店、服务、会员、活动、内容和数字界面是否提高关系质量。
7.经营结果：收入、同店、全价销售、利润、库存、现金流和区域表现能支持什么。

## 演化标签

沿用`新分支`、`强化`、`细化`、`修正`、`反转`、`从观点到行动`；暂时无法进入既有主线时使用`当前信号`。

## 来源等级

| 等级 | 来源 | 用途 |
|---|---|---|
| L1 | 公司财报、监管文件、官方战略与原始访谈 | 确认对象行动、口径和经营结果 |
| L2 | Bain／Altagamma等方法透明的行业研究 | 判断市场规模、客群、地区和品类变化 |
| L3 | BoF、Vogue Business、Jing Daily等专业媒体与高质量播客 | 发现人物、争议、机制和反证 |
| L4 | 人物Newsletter、X、访谈与公开演讲 | 记录可归因判断，不能单独证明行业趋势 |
| L5 | 榜单、社媒热度、搜索趋势和二手讨论 | 只负责发现或补充消费者语言 |

财报也带有管理层叙事；跨集团比较时统一会计口径、时间窗、汇率和品类边界。行业报告的预测与实际结果必须分开。

## 收录门槛

材料需有主体、日期、原始链接和新增信息，并至少改变一项：需求结构、品牌路线、产品与价格、文化创造、渠道控制、客户体验、组织配置或经营结果。

丢弃：

- 只列明星、红毯、秀场造型或单品热度。
- 只用社媒声量证明品牌吸引力或购买意愿。
- 无经营或消费者证据的「年轻化」「高端化」「文化破圈」。
- 单次折扣、联名或快闪，却无法说明对象路线和后续结果。
- 把全部高价消费、轻奢、美妆和奢侈品混成同一市场口径。

## 长期写入

```text
Domains/PR/60-References/Evidence/Luxury/<Entity>-Evidence.md
→ Domains/Business/Luxury/Entities/<Entity>.md
→ Domains/Business/Luxury/Luxury-Intelligence-Radar.md
```

对象档案最低包含「对象定位」「当前坐标」「更新记录」「演化主线」「证据边界」。信号升级至少需要两个独立对象、两类来源、可观察经营或消费者结果，并保留表现分化和反例。

## 对中国消费品PR的接口

聚合时优先回答：

- 奢侈品对产品价值、价格解释、稀缺、全价纪律和渠道控制提供什么边界。
- 品牌文化如何由产品、空间、服务和组织投入承接。
- 中国消费者的理性化、体验偏好、本土文化和二手市场如何改变信任与选择。
- 哪些方法只能由高毛利、长期工艺资产和高净值客群支撑，不能照搬到大众消费品。
