# PR人物思维演化模型

## 三层观察

1.传播环境：媒体、平台、公众情绪、监管、政治、信任和注意力结构发生了什么变化。
2.组织实践：企业如何调整发声、危机、治理、渠道、衡量、团队和AI应用。
3.人物判断：人物如何解释变化、调整主张、采取行动或暴露新矛盾。

## 演化标签

- `新分支`：开始讨论此前没有覆盖的问题。
- `强化`：新材料支持已有命题，没有改变边界。
- `细化`：增加机制、条件、对象或适用范围。
- `修正`：调整方向、缩小结论或承认旧判断不完整。
- `反转`：核心方向与旧判断相反。
- `从观点到行动`：把主张转为组织、流程、产品、投资、客户或企业动作。

`当前信号`只表示暂时无法与既有主线建立可靠关系，不属于第七类演化。

`内容性质`只使用`观点`、`行动`或`信息`。更新记录按来源发布时间倒序。证据列以「原文」为链接文字直接指向原始链接。

每条主线写「起点→推进／转折→当前判断→下一观察点」。只有认知或行动发生变化时才增加主线节点和关键转折。
