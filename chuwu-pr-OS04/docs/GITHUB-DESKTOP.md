# 用GitHub Desktop维护OS04

现有仓库为[chuwu57/Chuwu-PR-OS](https://github.com/chuwu57/Chuwu-PR-OS)，当前Skill目录为chuwu-pr-OS04/Skills。

首次获取：在GitHub Desktop选择File → Clone Repository，通过URL克隆上述仓库。已经克隆过时，切换到该仓库并Fetch origin／Pull origin获取OS04；有未提交改动时先保留和处理自己的修改。

后续修改在仓库内的chuwu-pr-OS04中进行。检查Changes，填写提交说明并Commit to main，再Push origin更新同一个仓库；无需重新Publish一个同名仓库。

只复制SKILL.md可能丢失共享依赖。请保留整个chuwu-pr-OS04目录，安装与运行范围见[依赖说明](DEPENDENCIES.md)。

官方说明：[克隆仓库](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop)。
