# 分享副本与原件的差异

原件留在初五的知识库，本包是独立文件副本，不包含指向原件的符号链接。

- 只选用户点名的13个Skill，保留运行参考、模板与脚本。
- 未导出历史Test-Cases、Feedback及缓存。Follow Loop依赖当前筛选规则，因此保留该段规则并移除个人选择历史。
- 补充年度战略必需的3份Workflow、PR交接协议、决策门与输出质量框架。
- 每个Skill附分享版使用范围说明；年度战略按合集根目录解析路径；Follow Loop明确自建知识库接入条件，并以PR_KNOWLEDGE_ROOT替代原机绝对路径示例。原脚本未改写。
- 能在包内定位的Wiki链接转成Markdown链接，未附带的知识条目标为外部依赖，未复制整套私人知识库来填充链接。
- registry.yml只保留所选13项；加入README、归属、依赖、GitHub Desktop说明和.gitignore。

SHA256清单记录导出文件内容；source_sha256用于核对原文件快照。哈希只证明内容一致性，不证明真实作者身份或业务质量。
